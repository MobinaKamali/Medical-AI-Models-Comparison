## Review Criteria

Each paper was analyzed according to:

- Disease
- Dataset
- Preprocessing
- Machine Learning / Deep Learning Models
- Best Performing Model
- Evaluation Metrics
- Advantages
- Limitations
- Clinical Applicability
- External Validation
- Clinical Validation

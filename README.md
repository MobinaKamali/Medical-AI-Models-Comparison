# Medical AI Models Comparison

## Overview

This repository presents a comparative review of Machine Learning (ML) and Deep Learning (DL) techniques for medical diagnosis and disease prediction based on 20 recent peer-reviewed research articles.

The project aims to compare different AI models, datasets, preprocessing techniques, evaluation metrics, and overall performance while highlighting their strengths, limitations, and potential for real-world clinical applications.

---

## Objectives

- Review recent AI-based medical diagnosis studies
- Compare Machine Learning and Deep Learning models
- Analyze datasets and preprocessing methods
- Compare evaluation metrics
- Identify the best-performing models
- Evaluate clinical applicability
- Investigate external and clinical validation

## Evaluation Metrics

The reviewed studies commonly reported:

- Accuracy
- Precision
- Recall (Sensitivity)
- Specificity

- ROC-AUC
- Matthews Correlation Coefficient (MCC)

---

## Key Findings

- Deep Learning models generally achieved superior performance for medical image analysis.
- Machine Learning models performed well on structured clinical datasets.
- CNN-based architectures were the most frequently used deep learning models.
- SVM, Random Forest, and XGBoost were the strongest traditional machine learning algorithms across multiple studies.

---

## Common Limitations

Most studies shared similar limitations:

- Lack of external validation
- Lack of clinical validation
- Small or single-center datasets
- Limited generalizability
- Limited deployment in real-world clinical settings

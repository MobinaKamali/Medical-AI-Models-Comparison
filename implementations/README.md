# Open-source Implementations

This folder contains references to open-source implementations related to the reviewed papers.

## Brain Tumor Segmentation

### MONAI

https://github.com/Project-MONAI/MONAI

MONAI is an open-source framework for developing AI solutions in medical imaging.

---

### nnU-Net

https://github.com/MIC-DKFZ/nnUNet

nnU-Net is a self-configuring framework for biomedical image segmentation and was one of the implementations related to the reviewed brain tumor study.

---

## Notes

Most reviewed papers implemented their models using frameworks such as:

- PyTorch
- TensorFlow
- Scikit-learn
- H2O AI

However, only a limited number of studies provided publicly available source code.
